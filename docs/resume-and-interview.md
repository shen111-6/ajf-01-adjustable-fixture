# 可放入简历的项目条目

**可调定位夹具设计与软件验证｜SolidWorks、AutoCAD｜AI辅助个人项目**
- 围绕25～100mm矩形工件定位需求，基于3-2-1定位思想完成夹爪、端挡块、丝杆及锁紧结构设计，形成29实例装配、6张二维标注图和BOM。
- 建立25/60/100mm三种静态装配并执行实体干涉检查，识别并修正丝杆长度、挡块间隙和旋钮啮合问题；完成原生模型、图纸及文件引用验收。
- 对400N假设工况开展局部强度和紧固连接初步计算，分析摩擦系数变化的影响，形成工艺路线、设计风险记录和样机验证方案。

## 面试讲解顺序
1. 问题：让不同尺寸矩形件靠同一组基准完成桌面定位。
2. 定位：底板A控制三个自由度，固定夹爪B两个，端挡块C一个；定位和夹紧分工。
3. 取舍：手动丝杆+滑动夹爪结构简单，锁紧依赖摩擦；不宣称切削能力。
4. 修订：95→150mm推杆、小开口20→25mm、旋钮端面相接→12mm啮合。
5. 证据：三个实际装配、干涉分类、尺寸与引用检查、Pack and Go重开。
6. 限制：尚无样机，摩擦与连接柔度的理论假设不能当实测结果。
