# 样机验证计划（尚未执行）

1. 尺寸核对：卡尺检查外形/孔距/槽宽，量具校准状态记录。螺纹通止规检查M6/M10；平面度/垂直度按图纸目标验收。
2. 空间核对：实际装配检查M8螺栓末端与桌面至少留2mm；25mm开口时挡块无碰撞；100mm时推杆仍完整穿过支架。
3. 夹紧力：力传感器或测力计记录推杆扭矩0.2/0.4/0.6N·m对应推力，不能把理论K系数当校准数据。
4. 静态滑移：在已测夹紧力不超过400N情况下，百分表观察固定夹爪和支架位移；记录拧紧扭矩、表面清洁度。逐级加载，发现滑移即停止并修订正向定位结构。
5. 重新装夹：同一工件拆装10次，保持扭矩/方向/清洁一致，百分表或高度尺记录X/Y零点最大差；记录量具分辨率，不能报告低于分辨率的效果。
